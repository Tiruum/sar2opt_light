# SAR2OPT Light

## Project Status (April 2026)

This repository is currently developed and maintained exclusively for CFRWD.
All active experiments, model changes, optimization work, and analysis are performed in the CFRWD pipeline.

The pix2pix part of the repository is kept as a historical artifact:
- preserved for reproducibility and legacy comparisons;
- not under active feature development;
- not the target of current research work;
- only maintained when needed for repository-level stability.

## Active Work Area: CFRWD

Primary locations for ongoing work:
- src/models/cfrwd
- docs/cfrwd
- checkpoints/cfrwd
- output/cfrwd
- src/models/cfrwd/config.yaml

## Historical Area: pix2pix

The pix2pix tree remains available for reference only:
- src/models/pix2pix
- docs/pix2pix
- checkpoints/pix2pix
- output/pix2pix

## Scope Policy

When contributing to this repository:
1. Prioritize CFRWD for all new experiments and improvements.
2. Treat pix2pix as archived legacy code.
3. If a change touches pix2pix, document the legacy compatibility reason.

## Setup

1. Create and activate a Python environment.
2. Install dependencies from requirements.txt.
3. Use CFRWD modules and configuration files for training, inference, and evaluation workflows.
