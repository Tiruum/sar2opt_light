# LLW-Former — устройство и работа модели

> **LLW-Former** = *Learnable Lifting Wavelet Former*. Финальная модель перевода
> SAR → оптика в этой работе. В коде живёт в `src/models/llwt_v5/` (исторические
> имена классов содержат «v4» — это легаси, модуль активный, см. ниже).
>
> Документ описывает **победную конфигурацию `llwt-v0.5.1-hfd`** (HF-D включён,
> aligner и FFS выключены). Все ссылки вида `файл:строка` указывают на исходный код.
> Значения гиперпараметров — из `src/models/llwt_v5/config.yaml`.

---

## 1. Идея в двух абзацах

Задача SAR→оптика плохо обусловлена: одноканальная радиолокационная интенсивность
не несёт однозначной информации о цвете и сезоне, отягощена спекл-шумом и
геометрическими искажениями. Базовые GAN (Pix2Pix, CycleGAN) замыливают
высокочастотные детали, теряют мелкие объекты и галлюцинируют топологию.

LLW-Former бьёт по двум местам сразу:

1. **Вейвлеты на входе и выходе.** Стандартный «патч-эмбеддинг» бэкбона заменён
   на **двухуровневый Хаар-стем**, а RGB-голова — на **обратное преобразование
   Хаара (IHaar)**. Сеть учится предсказывать не пиксели, а вейвлет-подполосы;
   высокие частоты (контуры, текстуры) моделируются явно.
2. **Высокочастотный дискриминатор HF-D** (главная новизна). Дополнительный
   критик судит только о высокочастотном остатке `h(x) = x − G_σ * x`. Он давит на
   генератор там, где обычный PatchGAN близорук, и при этом работает **только на
   обучении** — на инференсе стоимость не растёт.

Бэкбон — предобученный **ConvNeXt V2**: переносим знание о статистике естественных
изображений в домен, где парных данных мало.

## 2. Полный проход (forward pass)

```
x_SAR (B,1,256,256)
   │
   ▼  SARAdapter          blocks.py:45      → физически осмысленные 3 канала
x_3   (B,3,256,256)
   │
   ▼  HaarStemProjection  gen.py:83         → 2-уровневый Хаар вместо patch-embed
f_0   (B,96,64,64)                            (96 — для Tiny; 128 — для Base)
   │
   ▼  ConvNeXt V2 (4 стадии)  gen.py:223     → пирамида признаков
{s0,s1,s2,s3} = (96,64²),(192,32²),(384,16²),(768,8²)
   │
   ▼  Decoder: 4× ConvUpsampleBlock  gen.py:274  → PixelShuffle ×2 + skip + GN/GELU
S_feat (B,32,128,128)
   │
   ▼  subband_head: Conv 7×7 (zero-init)  gen.py:285  → 12 = 3 RGB × 4 подполосы
S     (B,3,4,128,128)                         предсказанные подполосы Хаара
   │
   ▼  InverseHaarUp (1 уровень)  gen.py:125  → точная реконструкция H/2 → H
z     (B,3,256,256)                           логиты до активации
   │
   ▼  tanh                gen.py:360
ŷ     (B,3,256,256) ∈ [-1,1]
```

Класс генератора — `LLWv4Generator` (`gen.py:188`). При `return_internals=True`
возвращает `(ŷ, S, f_0)` для визуализации (`gen.py:362`).

## 3. Компоненты генератора

### 3.1 SARAdapter — `blocks.py:45`
Превращает 1-канальный SAR в 3 физически осмысленных канала
(`forward`, `blocks.py:85`):

| Канал | Что это | Код |
|------|---------|-----|
| 1 | исходная амплитуда `x` в `[-1,1]` | `blocks.py:85` |
| 2 | **адаптивный фильтр Ли** в лог-области (`lee_despeckle`, fp32) — давит спекл | `blocks.py:71`, `:19` |
| 3 | **модуль градиента Собеля** `√(gx²+gy²)` — подчёркивает границы | `blocks.py:79` |

Затем `Conv2d(3→3, k=3, reflect-pad, bias=False) + GELU` (`blocks.py:64`). Ядра
Собеля фиксированы (`register_buffer`), обучается только проекция (27 весов).
Включается флагом `gen.use_sar_physics: true` (config), иначе — наивная свёртка
`1→3` (`gen.py:219`).

### 3.2 Хаар-стем — `HaarStemProjection` (`gen.py:83`)
Заменяет штатный стем ConvNeXt V2 (свёртка 4×4, страйд 4) на **фиксированное
двухуровневое ортонормированное преобразование Хаара**:

- Уровень 1: `x_3` → {LL₁,LH₁,HL₁,HH₁} на H/2.
- Уровень 2: на LL₁ → {LL₂,LH₂,HL₂,HH₂} на H/4.
- **LL₁ отбрасывается**; LL₂+детали 2-го уровня берутся на H/4 как есть, детали
  1-го уровня усредняются (avg-pool ×2) до H/4 (`gen.py:107`).
- Итого `7 × in_channels = 21` канала (12 со 2-го уровня + 9 с 1-го) → `Conv 1×1
  (21→96) + LayerNorm` (`gen.py:94`, `:111`).

Преобразование фиксировано (`haar_weights` — `register_buffer`, `blocks.py:105`),
обучается только проекция 1×1. Зачем два уровня: понижение до H/4 совмещает
геометрию с входом ConvNeXt V2 без обучаемого даунсэмплинга.

### 3.3 Бэкбон ConvNeXt V2 — `gen.py:223`
- Грузится из HuggingFace: `facebook/convnextv2-tiny-22k-224` (config) через
  `transformers.AutoBackbone` (`gen.py:227`). Есть фолбэк на локальные файлы
  при сбое сети (`gen.py:233`).
- `out_indices=[1,2,3,4]` → 4 стадии, каналы `(96,192,384,768)` для Tiny
  (`(128,256,512,1024)` для Base).
- Штатный стем **заменён** на Хаар-стем (`gen.py:266`), остальные 4 стадии — с
  предобученными весами без изменений.
- Особенности v2: блок GRN (Global Response Normalization) + предобучение через
  маскированное автоэнкодирование (FCMAE) — ценно при дефиците парных данных.

### 3.4 Декодер — `gen.py:274`, блок `ConvUpsampleBlock` (`blocks.py:115`)
4 блока, каждый удваивает разрешение через **PixelShuffle ×2** (`blocks.py:128`),
конкатенирует skip-признаки соответствующего уровня энкодера и прогоняет через
`2×(ReflectionPad + Conv3×3 + GroupNorm + GELU)` с остаточной связью:

| Блок | Каналы | Разрешение | Skip |
|------|--------|-----------|------|
| up4 | 768→256 | H/32→H/16 | s2 |
| up3 | 256→128 | H/16→H/8 | s1 |
| up2 | 128→64 | H/8→H/4 | s0 |
| up1 | 64→32 | H/4→H/2 | нет |

`GroupNorm` держит градиент устойчивым при малых батчах. Билинейная
интерполяция — **только** в опциональном `detail_residual` (по умолчанию OFF,
`gen.py:303`); основной апсэмплинг — чисто PixelShuffle.

### 3.5 Голова Inverse-Haar — `gen.py:281`, `InverseHaarUp` (`gen.py:125`)
- `subband_head`: `ReflectionPad2d(3) + Conv2d(32→12, k=7)`, **zero-init**
  (`gen.py:285`). 12 = 3 RGB × 4 подполосы на H/2.
- Реформат в `(B,3,4,H/2,W/2)`, разбивка на LL,LH,HL,HH (`gen.py:342`).
- `InverseHaarUp` — **одноуровневое** обратное Хаар-преобразование
  (`Wᵀ`-einsum + `pixel_shuffle ×2`), H/2 → H (`gen.py:171`). Точный обратный
  оператор: `Wᵀ = W⁻¹`, до машинного нуля.
- Финал: `tanh(logits)` (`gen.py:360`).

> **Асимметрия дизайна:** стем — 2 уровня DWT, голова — 1 уровень IHaar.
> Голова предсказывает подполосы на H/2 и поднимает до H; нижний уровень уже
> восстановлен декодером.

> **Тёплый старт:** zero-init головы ⇒ подполосы = 0 ⇒ `IHaar(0)=0` ⇒
> `tanh(0)` = серая картинка. Обучение стартует из нейтрального состояния, без
> взрыва градиентов (`gen.py:283`).

**Ветвей и обучаемых весов слияния нет** — генератор одноветочный (в отличие от
CFRWD с его `fusion_weight`). Единственное «слияние» — skip-конкатенации U-Net.

## 4. Дискриминаторы — `dis.py`

Обёртка `LLWFormerDiscriminator` (`dis.py:347`) держит несколько голов. В победной
конфигурации **активны ровно две**: `MainDis` и `HighFreqDis`.

### 4.1 Главный дискриминатор `MainDis` — `dis.py:156`
- **Двухмасштабный условный PatchGAN** в стиле pix2pixHD: грубая ветвь (5 свёрток,
  RF ≈ 70×70) + тонкая ветвь (4 свёртки, RF ≈ 46×46).
- **Без спектральной нормализации** (`use_sn=False`, `dis.py:156`, `:387`).
  Причина: SN вместе с тяжёлым FM (вес 10) глушит состязательную динамику.
- Условный: вход `cat([InstanceNorm(SAR), optical])`, `in_channels=4`
  (`dis.py:161`).
- Возвращает `((logits_coarse, logits_fine), feats)` — промежуточные активации
  идут в Feature Matching (`dis.py:166`).

### 4.2 HF-D `HighFreqDis` — `dis.py:300` (главная новизна)
- Судит о **высокочастотном остатке** `h(x) = x − gaussian_blur(x, σ)`, **σ = 2**
  (`dis.py:321`, config). Блюр в fp32 (`align.gaussian_blur`).
- **Спектральная нормализация на каждой свёртке** (`_sn`, `dis.py:312`) — здесь
  она критична (ранний subband-D без неё расходился, логиты ~10⁵).
- Условный: `cat([InstanceNorm(SAR), h(opt)])`, `in_ch=4` (`dis.py:332`).
- LSGAN. Потери:
  - `L_{D_H} = ½·E[(D_H([s,h(y)])−1)²] + ½·E[D_H([s,h(ŷ)])²]`
  - `L^G_H   = E[(D_H([s,h(ŷ)])−1)²]`, вес `λ_H = 1` (`hfd_weight`, config).
- **Только на обучении.** В обёртке HF-D — отдельный атрибут, не часть основного
  `forward` (`dis.py:378`); вызывается лишь в `training_step` (`main.py:214`,
  `:376`). `validation_step` зовёт только `netG` (`main.py:526`).
- **Аддитивен и абляционно чист:** при `λ_H = 0` модель точно сводится к базовой.

### 4.3 Выключенные головы
| Голова | Класс | Статус | Почему |
|--------|-------|--------|--------|
| Subband-D | `SubbandDis` (`dis.py:193`) | OFF | логиты взрывались до ~1.8e5 |
| Fourier-D | `FourierDis` (`dis.py:241`) | OFF | не дал выигрыша |
| Aligner (φ-поле + PSC) | `DeformationAligner` | OFF | плотная регистрация невозможна, NCC≈0.02 |

## 5. Функция потерь генератора

Собирается аддитивно в `training_step` (`main.py:346`). Критерий создаётся, только
если вес > 0 (`factory.build_criterions`, `factory.py:88`).

| Слагаемое | Вес | Назначение |
|-----------|-----|-----------|
| GAN (main, LSGAN) | **1.0** | состязательный сигнал |
| Feature Matching (main) | **10.0** | L1 по активациям D; снижение до 1 теряло >1 дБ PSNR |
| **GAN (HF-D)** | **1.0** | высокочастотный критик (новизна) |
| MS-SSIM (`1−MS-SSIM`) | **1.0** | структурное подобие |
| Per-band Haar L1 | **2.0** | L1 по подполосам vs `HaarDown(y)`, веса `(LL,LH,HL,HH)=(1,1.5,1.5,2)`, норм. на Σ |
| LPIPS (**AlexNet**) | **2.0** | перцептивная близость |
| FFL (Focal Frequency, α=1) | **10.0** | согласование Фурье-спектров |
| PatchNCE (CUT) | **0.1** | контраст; слои `{0,1,2,3}`, N=256, τ=0.07 |

**Пиксельного L1 НЕТ** (`l1_weight=0`) — L1 живёт только в вейвлет-базисе
(per-band). Тип GAN — **LSGAN** (`gan_type: lsgan`), сглаживание меток
`real=1.0, fake=0.0` (намеренно 1.0, чтобы выбить вырожденную точку 0.45).

Потеря D: `0.5·(GAN_real + GAN_fake)` для main + то же для HF-D (`main.py:242`).
R1-штраф выключен (`r1_gamma=0`).

## 6. Обучение — `main.py`

- **Ручная оптимизация** (`automatic_optimization=False`, `main.py:61`).
- Порядок: `configure_optimizers → [opt_d, opt_g]` (`main.py:156`); на шаге сперва
  D (на detached fake), затем G (свежий forward с градиентами).
- Оптимизаторы: G — **AdamW**, D — **Adam**, оба `lr=2e-4`, betas `(0.5,0.999)`
  (`factory.py:198`, config). Клиппинг градиента: `clip_d=5.0`, `clip_g=1.0`.
- Расписание LR: `linear_decay` — константа 150 эпох, линейный спад последние 50
  до `eta_min=1e-6` (`main.py:600`).
- **EMA** весов, decay 0.999, со старта эпохи 20; финальная оценка — по EMA.
- Точность `bf16-mixed`, NHWC (channels_last), 200 эпох.
- **Тёплый старт** G+D из `checkpoints/llwt_v45/llwt-v0.4.6-align-ws/last.ckpt`
  (`strict=False`, config) — отсюда же легаси-имена «v45» в путях артефактов.
