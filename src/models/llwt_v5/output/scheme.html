LLW-Former — общая схема: потоки данных, выходы и лоссы

вход генератор выходы / реконструкция Main-D HF-D

Пунктир = условие/real-проход. Дискриминатор условный: SAR склеивается с изображением по каналам ([SAR ⊕ opt] для Main-D, [SAR ⊕ hp(opt)] для HF-D). Каждая D-голова прогоняется дважды — на real и на fake.
